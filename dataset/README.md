## Datasets

This directory stores the datasets used in our experiments. Two datasets are used:

- [`linedp_dataset`](https://github.com/awsm-research/line-level-defect-prediction)
- [`glance_dataset`](https://github.com/Naplues/BugDet/tree/master/Dataset)

The directory structure is organized as follows:

```text
dataset/
├── linedp_dataset/
│   ├── File-level/
│   └── Line-level/
└── glance_dataset/
    ├── File-level/
    └── Line-level/
